# Cozy Queries

Generate thoughtful, warm questions for meaningful conversations using AI. Perfect for ham radio nets, ice breakers, and sparking engaging discussions.

## Quick Start (30 seconds)

1. **Open the app**: Visit https://yourusername.github.io/cozy-queries

2. **Choose your AI provider**:
   - **OpenAI**: Get your API key from https://platform.openai.com/api-key
   - **Anthropic**: Get your API key from https://console.anthropic.com/
   - **OpenRouter**: Get your API key from https://openrouter.ai/
   - **Ollama** (local): Install from https://ollama.ai and run `ollama serve`

3. **Enter your API key** (if using cloud AI)

4. **Generate questions**:
   - Enter a topic (e.g., "ham radio ice breakers", "winter cozy conversations")
   - Choose how many questions (1-50)
   - Click "Generate Questions"

5. **Use your questions** - Copy them for your net or conversation!

## Privacy Guarantee

**Your API key and questions NEVER leave your browser.**

- Keys are stored in your browser's localStorage only
- All API calls go directly from your browser to the AI provider
- We never see, store, or use your data
- Your questions are never used for AI training

## Features

- **Multiple AI providers**: OpenAI, Anthropic, OpenRouter, Ollama (local)
- **Adjustable quantity**: Generate 1-50 questions at a time
- **Mobile responsive**: Works on phones and tablets
- **Copy to clipboard**: Easy one-click copying
- **Share to Pastebin**: Share question lists online
- **Privacy-first**: All data stays in your browser
